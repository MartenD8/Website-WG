# 05 – Ausblick: mögliche zukünftige Funktionen

Ideen, die sich gut an den bestehenden Aufbau anschließen würden – **noch nicht umgesetzt**.

## Inhalte & Events

- Bild-Upload im Admin (statt nur URL)
- Event-Kategorien / Tags neben dem Level
- ICS-Export („Zum Kalender hinzufügen“)
- Countdown bis zum nächsten Event
- „Heute“-Hervorhebung im Kalender

## Community-Features

- Live-Rangliste Bier / Quiz auf der Startseite (ohne Admin)
- Kommentare oder „Stimmung des Abends“ (mit Moderation)
- Foto-Galerie pro Event (Upload + Freigabe durch Admin)
- Team-Challenges (mehrere Personen zusammen zählen)

## Quiz & Awards

- Mehrere Quiz-Runden / Fragen-Editor im Admin
- Awards-Ergebnisse nach Abstimmungsende öffentlich anzeigen
- Unentschieden-Regel / Stichwahl bei Awards
- Quiz-Zeitlimit oder Anti-Cheat (IP-Rate-Limit)

## Admin & Betrieb

- Rollen (z. B. nur Lesen vs. voller Admin)
- Audit-Log (wer hat wann was geändert)
- Export als CSV/Excel (Gäste, Bier, Quiz, Awards)
- Automatische Backups von `wg.db`
- Umstieg auf SQLite/Postgres, falls mehr Traffic oder Multi-Server

## Design & UX

- PWA / Offline-Hinweis
- Barrierefreiheit weiter ausbauen (Screenreader-Texte, Kontraste)
- Eigene Brand-Typografie / Farbschema der WG
- Animationen beim Öffnen von Quiz-Ergebnis / Awards

## Integration

- Discord-/WhatsApp-Benachrichtigung bei neuer Anmeldung
- Videos automatisch komprimieren / Thumbnails erzeugen
- Domain/HTTPS-Checkliste als Admin-Statusseite

Bei Bedarf können einzelne Punkte aus dieser Liste als nächste konkrete Aufgabe spezifiziert und umgesetzt werden.
